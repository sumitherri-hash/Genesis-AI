Human interface · accessibility

Use GENESIS the way that works for you.

GENESIS is a responsive web app. The same interface can be opened in a browser on Android, iPhone/iPad, Windows and Mac. Installable app-like behavior depends on browser and operating-system support; separate native apps are not yet built.

Ways to interact

  • Touch: tap the composer and buttons on a phone or tablet.
  • Keyboard: type normally. Press Enter to submit and Shift + Enter for a new line. On the main page, Alt + Shift + G focuses the request box.
  • Voice: use the Voice button when your browser supports speech recognition and you grant microphone permission.
  • Screen reader: use VoiceOver on Apple devices, TalkBack on Android, or Narrator on Windows.
  • Switch / alternative access: use Android Switch Access, iOS/iPadOS Switch Control, macOS Switch Control, or Windows accessibility input devices.
  • Eye gaze: Windows Eye Control or compatible assistive hardware can operate supported browser controls.

Cross-platform status

  • Android, iPhone/iPad, Windows and macOS: responsive browser interface.
  • Installable PWA: supported browsers/platforms only.
  • Dedicated native Android, iOS, Windows and macOS apps: not yet built.

Touch-free control is not guaranteed on every device. GENESIS does not run an always-listening wake word or control the entire operating system.
